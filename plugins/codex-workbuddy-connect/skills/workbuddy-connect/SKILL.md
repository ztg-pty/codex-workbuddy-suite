# WorkBuddy 双区连接

调用该插件提供的本机 MCP 工具完成用户要求的只读诊断。

1. 用 `workbuddy_status` 检查共享运行时和两区连接。
2. 需要账号与余额信息时，用 `workbuddy_accounts`。
3. 需要官方模型目录时，用 `workbuddy_models`，`region` 取 `cn`、`intl` 或 `all`。用户未指定区域时取 `all`。

直接保留工具返回的官方模型名称、官方模型 ID 和 WorkBuddy 区域前缀。不要将模型名称改成自创别名，不要自行推断缺失的模型、余额、签到或账号状态。说明余额单位和查询时间；接口未返回的项目明确标为未返回。

模型目录可读、账户接口成功、MCP 启动成功以及当前 Codex 聊天实际使用 WorkBuddy 模型，是分别需要证据的状态。当前聊天主模型是否接入，以该聊天的运行时请求证据为准。不要以本插件的状态工具调用替代主模型验证。

共享运行时连接文件默认位于当前用户的 `.codex/workbuddy-suite/connection.json`。仅包含本机服务地址和本机随机服务密钥，账号凭据由共享运行时读取。不要请求用户将账号 token 发到聊天；不要读取或展示账号凭据、Cookie、Authorization、服务密钥及连接文件内容。

工具报告运行时未启动时，说明当前检查未完成，依据已经授权的本机安装/启动流程处理；不要修改 Codex 的主模型配置或重启应用来冒充完成诊断。开源分发只包含代码和说明；不要上传个人账号文件、运行时密钥或余额记录。
