# WorkBuddy 国内签到

`workbuddy_checkin_status` 只读查询当前国内区账号的今日签到状态。用户要求签到时，先用它判断当前记录，再用 `workbuddy_checkin` 执行已授权的签到。已有明确签到指令时无需重复请求确认；用户只要求查看状态时，仅调用状态工具。

签到仅针对工具报告的当前国内区账号。根据工具实际返回，区分已签到、签到成功、重复签到、执行失败、账号未登录、状态未知。执行后查看状态记录，报告实际日期、奖励与余额变化；接口没有返回的数值不要补写。

共享运行时负责当日去重、官方请求和签到记录。本工具执行失败或超时后，不自动连续重试签到；先查询状态，避免未知结果下重复提交。不得将国际区账号、模型接入或其他平台活动推断为支持签到。

两个插件共用当前用户 `.codex/workbuddy-codex` 下的本机运行时。不要读取或展示账号 token、Cookie、Authorization、本机服务密钥和连接文件内容。工具报告运行时不可用或未登录时，明确签到未完成，并按已授权的本机启动或登录流程处理。

签到状态和成功结果只证明账号签到；不要宣称当前 Codex 聊天因此切换了主模型。本插件是私人本地包，不用于公开上传。
